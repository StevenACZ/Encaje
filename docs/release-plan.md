# First public release

The first public release is **Encaje 1.0.0, build 10**, dated **2026-09-06**.
It targets Apple Silicon Macs running macOS 14 or later and uses the MIT license.

## Scope

- Custom grid zones, configurable shortcuts, geometry undo/redo and reference outlines.
- Movement between monitors, saved workspaces, exclusions and native Accessibility setup.
- English and Spanish interfaces, optional launch at login and menu bar controls.
- Developer ID signed and notarized distribution artifacts.
- Sparkle 2 signed in-app updates, optional daily checks and explicit installation.
- Separation between Apple Development builds and the public update feed.
- English and Spanish READMEs, contribution guidance and a security policy.

The [release checklist](releasing.md) governs artifact validation and publication.
Release readiness depends on the actual gates and interactive verification; this
scope document does not certify that they have passed. Performance claims require
measured evidence with the limits described in [validation](validation.md).
